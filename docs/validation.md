# 验证范围

本文件区分自动诊断与实际使用验收，具体公开整理版结果记录在本目录的 `validation-results.json`。

合成音频、配置读写、100 项窗口逻辑、95 项本程序隐藏窗口/原生控件检查，以及 13 项转写桥接测试，不使用真实音频设备或真实模型。隐藏窗口检查不是桌面鼠标键盘自动操作。

整理前相同 UI 的开发版本，隐藏窗口待机工作集峰值为 14.551 MiB，私有提交峰值为 2.594 MiB。此历史测量不包含采集或 ASR，也不代表整理后重编译产物的新测量结果。20 MB 是原生主进程的待机目标，不是开启模型后的全进程总内存承诺。

以下项目仍需真实环境人工验证：

- 新版麦克风与系统声音同时采集。
- 指定程序声音隔离及程序重启场景。
- 真实微信通话触发与误触发。
- 真实鼠标拖动手感、键盘交互和跨不同 DPI 显示器拖动。
- 重新登录后的自启动，以及 Explorer 重启后的托盘恢复。

默认不自动录音、不自动启用自启动、不自动下载模型。
