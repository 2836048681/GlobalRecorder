# 验证范围

本文件区分自动诊断与实际使用验收，具体公开整理版结果记录在本目录的 `validation-results.json`。

合成音频、配置读写、100 项窗口逻辑、95 项本程序隐藏窗口/原生控件检查，以及 13 项转写桥接测试，不使用真实音频设备或真实模型。隐藏窗口检查不是桌面鼠标键盘自动操作。

整理前相同 UI 的开发版本，隐藏窗口待机工作集峰值为 14.551 MiB，私有提交峰值为 2.594 MiB。此历史测量不包含采集或 ASR，也不代表整理后重编译产物的新测量结果。20 MB 是原生主进程的待机目标，不是开启模型后的全进程总内存承诺。

以下项目仍需真实环境人工验证：

- 新版麦克风与系统声音同时采集。
- 指定程序声音隔离及程序重启场景。
- 真实微信通话触发与误触发。
- 真实鼠标拖动手感、键盘交互和跨不同 DPI 显示器拖动。
- 重新登录后的自启动，以及 Explorer 重启后的托盘恢复。

默认询问是否录音，不自动开始录音、不自动启用自启动。缺少转写组件时询问，用户确认后才下载。

新增的 `--prompt-test` 覆盖 QQ/微信名称、监听范围、持续活动与短暂静音去重，以及录音/下载确认窗在四种缩放下的布局、默认取消和确认分支。诊断的确认分支只计数，不采集音频或下载任何文件。

`--animation-test` 在本程序隐藏窗口内对比完整面板重绘与缓存合成各 80 帧，记录 200% 缩放下的每帧耗时及 DIB/GDI 资源复用。该结果用于验证渲染开销，不能当作真实桌面显示帧率或真人手感验收。

本轮公开版二进制的隐藏窗口待机诊断峰值工作集为 15.227 MiB、私有提交为 3.316 MiB，不含音频、模型或安装过程。200% 缩放下完整重绘 P95 为 4.0102 ms，缓存合成 P95 为 1.0621 ms；具体硬件和系统负载会影响测量。

安装器在 Windows PowerShell 5.1 下通过 28 组离线测试、148 项断言，包括镜像顺序与备用源、固定哈希、无 Python 引导模拟、失败保留、重复复用、并发锁和目录移动保护。真实首次联网安装、干净电脑兼容性和真实转写仍为 NOT_RUN；镜像的完整 GET 下载链路也未在此验证中执行，不把元数据/HEAD 探测当作完整下载验收。
